Política de Privacidad

Proyecto: Agente de Soporte Inteligente Tipo: Software de Código Abierto / Fines Educativos Última actualización: Octubre 2026

Aviso de Propósito Educativo y No Lucrativo: Esta aplicación y su código fuente han sido concebidos exclusivamente con propósitos formativos, pedagógicos y de práctica técnica en arquitecturas de Inteligencia Artificial y computación en la nube. No presta servicios comerciales, no genera ingresos monetarios y no comercializa datos de ninguna naturaleza.

1. Información General

Esta Política de Privacidad describe de manera detallada, transparente y explícita cómo el proyecto Agente de Soporte Inteligente (en adelante, "la Aplicación" o "el Software") accede, procesa y gestiona la información proveniente de los servicios de Google (específicamente Google Sheets y Google Drive API) y la API de Google Gemini.

2. Cumplimiento de la Política de Datos de Usuario de los Servicios de API de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida a través de las APIs de Google por parte de esta aplicación se apega rigurosamente a la Política de Datos de Usuario de los Servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de Uso Limitado (Limited Use Requirements).

Google API Services User Data Policy Compliance:
The Application's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

3. Datos a los que Accede la Aplicación

La aplicación solicita acceso de autorización únicamente a los recursos estrictamente indispensables para su ejecución:

  • Hojas de cálculo de Google Sheets: Acceso de lectura y escritura limitado exclusivamente a la hoja de cálculo específica (denominada por defecto Comentarios o configurada por el usuario) que contiene la lista de textos a procesar.
  • Contenido de los comentarios: Texto contenido en las columnas de comentarios de la hoja seleccionada para ser enviado al modelo de lenguaje.

La aplicación NO accede a: correos electrónicos personales (Gmail), contactos, calendarios, archivos ajenos en Google Drive, contraseñas ni información de facturación del usuario.

4. Finalidad del Procesamiento de Datos

Los datos a los que se accede se utilizan con el único propósito de:

  • Leer el texto del comentario de soporte pendiente de atención.
  • Transmitir dicho texto mediante llamada cifrada (HTTPS) a la API de Google Gemini para obtener una clasificación temática (Ventas, Soporte Técnico, Logística) y una valoración del sentimiento (Positivo, Negativo, Neutro).
  • Escribir los resultados clasificados de vuelta en la misma fila de la hoja de cálculo de Google Sheets del usuario y marcar la columna de ejecución como procesada.

5. Almacenamiento, Retención y Seguridad de los Datos

  • Sin retención persistente: La aplicación no cuenta con base de datos externa ni almacena copias de los comentarios de los usuarios en servidores de terceros. El procesamiento de los datos se realiza en memoria volátil durante el tiempo de ejecución (ejecución efímera en Runner de GitHub Actions o máquina local).
  • Cifrado en tránsito: Todas las comunicaciones entre GitHub Actions / el cliente local, Google Sheets API y Google Gemini API se realizan utilizando protocolos seguros con cifrado TLS/HTTPS.
  • Seguridad de credenciales: Las claves de API y las credenciales de Service Account o Tokens OAuth se almacenan de forma cifrada en GitHub Secrets o en variables de entorno locales, impidiendo su exposición en el código fuente público.

6. No Compartición ni Comercialización de Datos

Dado el carácter no lucrativo y puramente educativo del proyecto:

  • No se venden ni alquilan datos: Bajo ninguna circunstancia los datos de los usuarios o de las hojas de cálculo se venden, transfieren o comercializan con terceras entidades o corredores de datos (data brokers).
  • Sin publicidad: Los datos no se utilizan para segmentación publicitaria, publicidad dirigida ni monetización de ninguna índole.
  • Sin entrenamiento indiscriminado: Los datos procesados no se utilizan para entrenar modelos de Inteligencia Artificial fuera de los términos contemplados por la API oficial de Google AI Studio / Gemini API.

7. Revocación de Permisos y Control del Usuario

El usuario o propietario de la cuenta de Google mantiene el control total de sus datos en todo momento y puede revocar el acceso concedido a la aplicación cuando lo desee:

  • Ingresando al panel de seguridad de Google: myaccount.google.com/permissions.
  • Seleccionando la aplicación y haciendo clic en Quitar acceso.
  • Si utiliza una Cuenta de Servicio (Service Account), simplemente removiendo el correo de la cuenta de servicio de los permisos de la hoja de cálculo en Google Sheets.

8. Contacto y Soporte del Desarrollador

Si tiene alguna duda, inquietud o sugerencia técnica respecto a esta política de privacidad o al funcionamiento del código abierto, puede abrir un Issue en el repositorio público de GitHub del proyecto o contactar directamente al autor del proyecto con fines formativos.
