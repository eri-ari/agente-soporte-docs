Automatización Inteligente de Soporte con Google Sheets & Gemini AI

Una solución de código abierto diseñada para analizar comentarios de clientes en tiempo real, clasificar solicitudes por categoría, detectar el sentimiento y actualizar hojas de cálculo de forma 100% desatendida en la nube.

Conocer la Arquitectura Política de Privacidad

Aviso Importante: Propósito Exclusivamente Académico y Demostrativo

Este software fue desarrollado con fines estrictamente educativos, pedagógicos y de práctica técnica. No tiene ningún fin comercial, lucrativo ni corporativo. No recopila datos personales para reventa ni entrenamiento de modelos, respetando estrictamente los términos de uso y privacidad de Google Cloud Platform y Google Workspace APIs.

Capacidades del Sistema

Construido con Python moderno para interactuar de forma segura con los ecosistemas de Google Cloud y GitHub.

Lectura y Escritura en Google Sheets

Sincronización bidireccional mediante gspread utilizando autenticación segura mediante Google Cloud Service Account o credenciales OAuth 2.0.

Clasificación & Sentimiento con Gemini

Procesamiento del lenguaje natural con Google Gemini Flash: clasifica automáticamente en Ventas, Soporte Técnico o Logística y etiqueta el sentimiento (Positivo, Negativo, Neutro) en formato JSON estricto.

Ejecución en Nube con GitHub Actions

Configuración de flujos automatizados (Cron triggers y manual dispatch) que ejecutan el agente en contenedores seguros sin necesidad de servidores locales encendidos.

Flujo de Automatización

Diseñado para operar en la nube de forma segura, respetando el principio de mínimo privilegio.

1

Disparo Automatizado en GitHub Actions

GitHub Actions inicia un Runner efímero en un intervalo programado (ej. cada 30 o 60 minutos) o bajo demanda manual.

2

Lectura de Filas Pendientes en Sheets

El agente se autentica mediante la clave segura de Service Account inyectada por GitHub Secrets y extrae únicamente las filas marcadas como no procesadas.

3

Inferencia con Gemini API

El texto del comentario se envía a la API de Gemini para clasificarlo y analizar su sentimiento sin almacenar información sensible en bases de datos externas.

4

Actualización y Marcado en la Hoja

Las columnas de Clasificación, Sentimiento y Ejecutado ("SI") se actualizan en la hoja y el proceso termina limpiamente.

Código Abierto y Transparente

Todo el código fuente está disponible públicamente para fines de auditoría técnica, aprendizaje de la comunidad y verificación de políticas de seguridad de Google Cloud.
